Enable Contours via Console

Instructions:

  1. Go to your bridge page (bridge.html)
  2. Open the browser console (F12)
  3. Copy and paste this code into the console:
// Find the MFD system const mfdSystem = window.mfdSystem || document.querySelector('.right-console')?.__mfd; if (mfdSystem) { const state = mfdSystem.getPageState('navigation'); if (state && state.overlaysVisible) { console.log('Current contours:', state.overlaysVisible.contours); state.overlaysVisible.contours = true; mfdSystem.setPageState(state, 'navigation'); console.log('✓ Contours enabled!'); console.log('New contours:', state.overlaysVisible.contours); } else { console.log('❌ Navigation state not found'); } } else { console.log('❌ MFD system not found'); }
  1. Press Enter
  2. You should see "✓ Contours enabled!" in the console
  3. The contours should now appear on the navigation display!

OR: Use the MFD Buttons

  1. On the bridge, look at the MFD (right console)
  2. Press the L5 button (labeled "SHOW")
  3. Press the L3 button (labeled "CONTOUR")
  4. The button should light up green, and contours will appear!
